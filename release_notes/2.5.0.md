**Tanium REST Release Notes - Published by Splunk June 23, 2026**


**Version 2.5.0 - Released June 23, 2026**

* Migrated app from legacy BaseConnector/taniumrest.json architecture to the soar_sdk App framework
* Replaced taniumrest_connector.py and taniumrest_consts.py with src/app.py using typed ActionOutput models and OutputField definitions
* Replaced taniumrest_view.py with src/views.py using Jinja2 HTML rendering and context["prerender"] support
* Added custom HTML widget view handlers for execute action, terminate process, parse question, run query, list processes, and get question results actions
* Added new HTML templates: taniumrest_action.html, taniumrest_parse_question.html with taniumrest wrapper class for SOAR widget rendering
* Replaced requirements.txt with pyproject.toml and uv.lock for dependency management
* Extracted Tanium REST API communication into dedicated src/tanium_client.py module
